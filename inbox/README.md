# Thả ảnh gốc vào thư mục này

Xem checklist đầy đủ tại [`CHECKLIST-ANH.md`](../CHECKLIST-ANH.md).

Ví dụ: chép `anh-01.jpg`, `anh-02.jpg`, `bg-hero.jpg` vào đây; khai báo chúng trong `assets.input.txt`; rồi chạy `npm run assets`.

Không cần tự resize hoặc nén ảnh. Script sẽ tạo bản WebP tối ưu trong `src/assets/photos/`.
